# Supplied Cangjie SDK snapshot

This reference records the SDK used for current Wirestack M0 implementation and verification. The binary archive itself is intentionally not committed.

| Field | Value |
|---|---|
| Compiler | `cjc 1.1.0-alpha.20260817040003 (cjnative)` |
| Default target | `x86_64-unknown-linux-gnu` |
| Package manager | `cjpm 1.1.3` |
| Proven platform | Linux x86_64 only |

## Use policy

- Load the SDK environment only in the local or CI job that needs it.
- Record the observed `cjc --version`, target, `cjpm --version`, OS, architecture, and repository commit in each durable report.
- Do not vendor the archive, extracted SDK, standard library binaries, or runtime binaries into Wirestack.
- Do not extrapolate this Linux result to another target or operating system.
- External SDK/std.net/runtime source snapshots remain read-only references unless an explicitly unlocked upstream task is executed in the upstream repository.
