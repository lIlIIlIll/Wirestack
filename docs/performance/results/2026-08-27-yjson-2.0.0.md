## 三库 release 门禁

最终批次保留 yjson、stdx.json 和 cjfast_json 的全部 36 个共同 workload。其中 13 行的
三库 CV 均不超过 5%，其余 23 行保留并标记为 noisy。固定门槛 workload 的 yjson 和
cjfast_json 两侧 CV 均不超过 5%。

| ProfileBundle encode / string | 10.767 µs | 12.338 µs | 0.845x | 11/11 | 2.13% / 4.59% |

CV 均不超过 5%。`N/P` 小于 1 表示 Native 延迟更低。

## 适用边界

这些结果只适用于上表源码、SDK、主机、API 和 workload。三库表比较等语义 typed codec；
Native 表比较同一 `YJson` API 的 Pure 与 Native 进程冻结状态。结果不代表所有 payload、
stream、DOM、allocation、RSS 或其他平台。

完整 release 判定见
[`release/2.0.0/evidence.md`](../../../release/2.0.0/evidence.md)。测量与复测规则见
