# 2026-09-05 T9 矩阵(bb43321 修复后)

本页记录修复批次 `bb43321` 的 T9 矩阵:Jackson 2.17.2(JMH 与手写计时双轨)对比
yjson / json4cj / cjjson,各跨 msgc 与 daily 两套工具链。归档位于
[`benchmarks/results/t9-matrix-20260905-bb43321/`](../../benchmarks/results/t9-matrix-20260905-bb43321/)(comparison、provenance、全部 cell 原始数据、checksums)。

## 结果状态

- **单次运行、CPU pinned(`--cpu 8`)**:每 cell 每用例一个 run。这是 diagnostic
  快照,**不是 release qualification**,不满足 0.1.0 发布倍数所需的 11 轮交替/反转
  A/B、跨 profile 重复前提。
- yjson 源绑定 `bb43321`(修复后树,逐文件 sha256 见归档 `provenance.json`);
  json4cj 绑定 pin `df20464838`;cjjson 为 server checkout。
- 两套工具链:msgc cjc 0.0.1(`--gc-mode=marksweep`)+ daily cjc
  1.1.0-alpha.20260829040003;server 96 核 `ubuntu2223131`。

## Geomean(基准 = Jackson;越小越快)

| 指标 | yjson | json4cj | cjjson |
| --- | ---: | ---: | ---: |
| msgc / Jackson | 1.018 | 2.576 | 5.111 |
| daily / Jackson | 2.466 | ABSENT(设计内) | 18.682 |
| serialize 组 (n=17) | 0.970 | 1.648 | 6.285 |
| deserialize 组 (n=11) | 0.981 | 4.497 | 4.023 |
| roundtrip 组 (n=2) | 1.884 | 5.373 | 3.286 |

Jackson 的 A 轨已是 bytes 原生解析,故其 bytes/string 比率按构造约为 1。

msgc cell 稳定在 ≈84 MB;daily cell 稳定在 ≈331 MB(marksweep 与默认 GC 的
堆行为差异);json4cj msgc 个别宽对象/极端值 case 上探至 86–119 MB。逐 case
数值见归档 `comparison.md`。

JMH 口径下手写数字显得更快)。逐 case 表见归档 `server/jackson-jmh/`。
