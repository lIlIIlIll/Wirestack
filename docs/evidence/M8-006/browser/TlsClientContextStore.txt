wirestack.tls.TlsClientContextStore

classpublicsemantic: partial src/tls/facade.cj:196:1

签名
public class TlsClientContextStore
⧉
概览

Atomically replaceable client context source.

Each handshake loads exactly one immutable snapshot. Replacement affects only handshakes that load afterward; existing handshakes and connections retain their original context and session partition.
