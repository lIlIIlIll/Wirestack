```cj
public init(
        maximumFrameBytes!: Int64 = 1024 * 1024,
        maximumMessageBytes!: Int64 = 16 * 1024 * 1024,
        ioBufferBytes!: Int64 = 16 * 1024,
        closeTimeout!: Duration = 5 * Duration.second
    )
```

Creates validated frame, message, masking\-buffer, and graceful\-close bounds\.
Control frames also obey the configured frame limit and a hard 125\-byte payload limit\.

#### 参数

- `maximumFrameBytes` — Maximum payload bytes retained or sent for one frame\.
- `maximumMessageBytes` — Maximum combined data payload across a fragmented message; control payloads are excluded\.
- `ioBufferBytes` — Maximum temporary chunk used while masking an outbound client frame\.
- `closeTimeout` — Maximum automatic Pong or close\-handshake budget; it only shortens an operation context\.
