```cj
        path!: String = "",
        secure!: Bool = false,
        httpOnly!: Bool = false
    )
```

Constructs a validated cookie\. Values use the RFC cookie\-octet subset and are not quoted or escaped\.

#### 参数

- `name` — Cookie name\.
- `value` — Cookie value\.
- `expires` — Optional absolute expiry\.
- `maxAge` — Optional relative lifetime in seconds\.
- `domain` — Optional Domain attribute; a leading dot is normalized away\.
- `path` — Optional Path attribute\.
- `secure` — Whether the Secure attribute is present\.
- `httpOnly` — Whether the HttpOnly attribute is present\.
