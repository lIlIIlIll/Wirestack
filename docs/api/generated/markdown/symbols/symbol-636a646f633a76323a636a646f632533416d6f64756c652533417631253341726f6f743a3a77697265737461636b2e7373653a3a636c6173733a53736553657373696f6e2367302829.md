### `wirestack.sse.SseSession.eventSource`

```cj
public static func eventSource(client: HttpClient, url: HttpUrl,
        headers!: HttpHeaders = HttpHeaders(), limits!: SseLimits = SseLimits(),
        policy!: SseSessionPolicy = SseSessionPolicy(), readBufferBytes!: Int64 = 16 * 1024,
        context!: OperationContext = OperationContext.background()): SseSession
```

Creates a lazy GET session\. Only this explicit policy can resubmit the GET\.
HTTP retries and redirects are disabled so the reconnect count bounds submissions\.

#### 参数

- `client` — Shared HTTP client, retained but never closed by the session\.
- `url` — GET resource; redirects must be resolved explicitly by the caller\.
- `headers` — Additional request headers; Accept and Last\-Event\-ID are session\-owned\.
- `limits` — Codec storage and per\-event work limits\.
- `policy` — Explicit reconnect, duration and active\-read idle bounds\.
- `readBufferBytes` — Maximum retained unread HTTP body chunk\.
- `context` — Parent absolute deadline, cancellation and event correlation\.

#### 返回值

A caller\-owned pull session, not an asynchronously running EventSource\.

### `wirestack.sse.SseSession.oneShot`

```cj
public static func oneShot(client: HttpClient, request: HttpRequest,
        limits!: SseLimits = SseLimits(), policy!: SseSessionPolicy = SseSessionPolicy(),
        readBufferBytes!: Int64 = 16 * 1024,
        context!: OperationContext = OperationContext.background()): SseSession
```

Sends an arbitrary request once and consumes its SSE response without any replay\.
A replayable POST body and client retry/redirect settings cannot change this rule\.

#### 参数

- `client` — Shared HTTP client, retained but never closed by this session\.
- `request` — Arbitrary one\-shot HTTP request; its method and body are preserved\.
- `limits` — Codec storage and work bounds\.
- `policy` — Lifetime and idle bounds; reconnect count has no effect for this mode\.
- `readBufferBytes` — Maximum retained unread body chunk\.
- `context` — Parent deadline, cancellation and correlation\.

#### 返回值

An owned session that never resubmits the request\.
