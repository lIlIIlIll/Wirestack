### `wirestack.http.HttpClient.connectWebSocket`

```cj
public func connectWebSocket(
        url: HttpUrl,
        protocols!: Array<String> = [],
        headers!: HttpHeaders = HttpHeaders(),
        webSocketLimits!: WebSocketLimits = WebSocketLimits(),
        context!: OperationContext = OperationContext.background()
    ): WebSocketConnectResult
```

Establishes an uncompressed WebSocket over HTTP/1\.1 or negotiated HTTP/2\.
Rejected handshakes return an owned response\. No redirects or retries replay the handshake\.

#### 参数

- `url` — Absolute HTTP or HTTPS URL of the WebSocket resource\.
- `protocols` — Ordered acceptable subprotocols\.
- `headers` — Additional headers excluding protocol\-managed fields\.
- `webSocketLimits` — Session frame, message and close bounds\.
- `context` — Shared handshake deadline and cancellation\.

### `wirestack.http.HttpClient.rotateTls`

```cj
public func rotateTls(value: HttpClientTlsConfig,
        policy!: HttpConfigurationRotation = HttpConfigurationRotation.Graceful): UInt64
```

Atomically installs validated TLS contexts in fresh direct/proxy pools\.
Graceful drains admitted exchanges\. SecurityReplacement cancels old work\.
Transferred HTTP/1 duplex sessions retain their original context until close\.

#### 参数

- `value` — Caller\-owned reusable TLS material; validation precedes publication\.
- `policy` — Explicit rotation policy, never inferred from certificate contents\.

#### 返回值

New TLS generation\. Failed validation or retention capacity preserves the old configuration\.
