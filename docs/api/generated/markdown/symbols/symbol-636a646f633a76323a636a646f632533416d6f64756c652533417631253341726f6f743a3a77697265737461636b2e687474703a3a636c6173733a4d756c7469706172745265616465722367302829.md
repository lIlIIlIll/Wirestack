### `wirestack.http.MultipartReader.init`

```cj
public init(body: ResponseBody, boundary: String,
        limits!: MultipartLimits = MultipartLimits(),
        context!: OperationContext = OperationContext.background())
```

Creates a reader for a response body\. After successful construction, the reader owns the body\.
It closes the body at the final boundary, on failure, or when close is called\.

#### 参数

- `body` — Multipart source body\.
- `boundary` — Boundary of 1 through 70 ASCII bytes containing only letters, digits, apostrophe, parentheses, plus, underscore, comma, hyphen, period, slash, colon, equals, or question mark\.
- `limits` — Bounds applied while headers and payload bytes stream from the source\.
- `context` — Cancellation and deadline checked before and after source reads\.
