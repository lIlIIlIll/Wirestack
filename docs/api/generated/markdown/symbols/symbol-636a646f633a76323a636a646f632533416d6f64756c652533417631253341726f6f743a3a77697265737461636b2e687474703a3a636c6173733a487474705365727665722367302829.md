### `wirestack.http.HttpServer.rotateTls`

```cj
public func rotateTls(value: HttpServerTlsConfig,
        policy!: HttpConfigurationRotation = HttpConfigurationRotation.Graceful,
        context!: OperationContext = OperationContext.background()): UInt64
```

Replaces validated TLS material atomically\. Graceful rotation drains old
connections; security replacement cancels and aborts them\. At most 64
referenced TLS generations may coexist\. Cleartext servers cannot rotate\.
The listener remains bound\. In\-progress handshakes retain their snapshot\.

#### 参数

- `value` — New certificate, key, authentication and TLS policy material\.
- `policy` — Explicit disposition of obsolete handshakes and connections\.
- `context` — Optional publication observation sink; rotation does not acquire a timeout budget\.

#### 返回值

The monotonically increasing listener\-local TLS generation\.
