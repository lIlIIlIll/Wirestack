# `wirestack.OperationTimeoutPolicy`

[包 `wirestack`](../packages/package-32303a636a646f633a6d6f64756c653a76313a726f6f7477697265737461636b.md)

```cj
public struct OperationTimeoutPolicy
```

Optional positive caps for operation stages and active reads\.
Each cap starts when its stage begins and is shortened by the context's
absolute deadline\. Body\-read timers do not run between caller read calls\.
Omitted values add no stage\-specific timer\.

Creates optional positive limits for network\-operation stages\.
Every configured value must be greater than zero\. None leaves that stage
governed by the operation's absolute deadline alone\.

#### 参数

- `requestAdmission` — Maximum wait for shared request\-resource admission\.
- `connectionPool` — Maximum wait for a reusable connection or stream\.
- `dns` — Maximum time for DNS resolution\.
- `tcpConnect` — Maximum time for the TCP connection plan\.
- `proxyConnect` — Maximum time for the HTTP CONNECT proxy exchange\.
- `tlsHandshake` — Maximum TLS handshake time\.
- `requestWrite` — Maximum request\-header and request\-body write time\.
- `responseHeaders` — Maximum wait for interim or final response headers\.
- `bodyReadIdle` — Maximum wait for response\-body progress during an active read\.
- `streamReadIdle` — Maximum wait for upgraded\-stream progress during an active read\.
