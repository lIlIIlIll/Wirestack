```cj
public init(maximumReconnects!: Int64 = 0,
        maximumDuration!: Duration = 5 * Duration.minute,
        initialRetryDelay!: Duration = Duration.second,
        minimumRetryDelay!: Duration = 50 * Duration.millisecond,
        maximumRetryDelay!: Duration = 30 * Duration.second,
        jitterPermille!: Int64 = 200,
        bodyReadIdle!: ?Duration = None<Duration>)
```

Creates bounded reconnect policy for GET EventSource sessions only\.

#### 参数

- `maximumReconnects` — Reconnect count, zero by default; at most 1000\.
- `maximumDuration` — Positive session lifetime, at most 24 hours\.
- `initialRetryDelay` — Initial backoff base\.
- `minimumRetryDelay` — Positive lower bound on each reconnect delay\.
- `maximumRetryDelay` — Upper bound on each reconnect delay, at most one hour\.
- `jitterPermille` — Jitter fraction, between zero and 1000\.
- `bodyReadIdle` — Positive active\-read cap, or the caller's existing cap\.
