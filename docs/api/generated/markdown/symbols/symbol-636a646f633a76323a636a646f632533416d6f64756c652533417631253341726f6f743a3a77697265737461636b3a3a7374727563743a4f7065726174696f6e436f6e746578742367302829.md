### `wirestack.OperationContext.init`

```cj
public init(
        deadline!: ?Deadline = None<Deadline>,
        cancellation!: CancellationToken = CancellationToken.none(),
        trace!: ?NetworkTraceContext = None<NetworkTraceContext>,
        eventSink!: ?NetworkEventSink = None<NetworkEventSink>,
        timeoutPolicy!: OperationTimeoutPolicy = OperationTimeoutPolicy()
    )
```

Creates an immutable operation context\.
Stage limits only shorten the absolute deadline; they do not change
cancellation, trace metadata, or the event sink\.

#### 参数

- `deadline` — Absolute upper bound for the complete operation\.
- `cancellation` — Token observed by this operation\.
- `trace` — Opaque trace identifiers propagated to network event sinks\.
- `eventSink` — Optional destination for network lifecycle events\.
- `timeoutPolicy` — Optional positive stage caps and active\-read idle limits\.
