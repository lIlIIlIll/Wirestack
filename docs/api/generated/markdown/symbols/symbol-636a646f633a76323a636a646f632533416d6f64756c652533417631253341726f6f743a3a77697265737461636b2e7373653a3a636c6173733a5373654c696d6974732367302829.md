### `wirestack.sse.SseLimits.init`

```cj
public init(maximumLineBytes!: Int64 = 16 * 1024,
        maximumEventBytes!: Int64 = 256 * 1024,
        maximumFieldsPerEvent!: Int64 = 1024,
        maximumBytesWithoutEvent!: Int64 = 1024 * 1024,
        maximumIdBytes!: Int64 = 4096,
        maximumRetryMilliseconds!: UInt64 = 60000u64)
```

Validates positive limits against fixed hard ceilings\.

#### 参数

- `maximumLineBytes` — Raw line bound, at most 1 MiB\.
- `maximumEventBytes` — Raw block bound, at most 16 MiB\.
- `maximumFieldsPerEvent` — Field count bound, at most 65536\.
- `maximumBytesWithoutEvent` — No\-progress wire bound, at most 64 MiB\.
- `maximumIdBytes` — Cursor bound, at most 64 KiB\.
- `maximumRetryMilliseconds` — Retry cap, at most one day; zero disables server delay\.
