```cj
        maximumParts!: Int64 = 128,

        maximumHeaderCount!: Int64 = 32,
        maximumPartBytes!: Int64 = 64 * 1024 * 1024,
        maximumBodyBytes!: Int64 = 128 * 1024 * 1024,
        readBufferBytes!: Int64 = 16 * 1024
    )
```

Creates a validated set of multipart parser limits\.

#### 参数

- `maximumParts` — Maximum number of parts, from 1 through 4096\.
- `maximumHeaderBytes` — Maximum bytes across one part's header block, from 1 through 1048576\.
- `maximumHeaderCount` — Maximum header fields in one part, from 1 through 1024\.
- `maximumPartBytes` — Maximum payload bytes in one part; nonnegative and no greater than maximumBodyBytes\.
- `maximumBodyBytes` — Maximum source bytes including multipart framing; must be nonnegative\.
- `readBufferBytes` — Source\-read and part\-discard buffer size, from 1 through 1048576 bytes\.
