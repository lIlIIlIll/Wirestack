Secret\-safe structured network evidence\.

Header names/values, URLs, bodies, certificates and arbitrary messages are
intentionally absent, so default instrumentation cannot accidentally expose
credentials or payload data\.

- `trace` — 要传播的追踪元数据。
- `requestId` — Logical request identifier shared by all attempts\.
- `attemptId` — Identifier for one protocol or connection attempt\.
- `streamId` — HTTP/2 stream identifier scoped to connectionId\.
- `connectionAttemptIndex` — One\-based Happy Eyeballs candidate position\.
- `stage` — Current operation stage, when applicable\.
- `timeoutReason` — Total deadline or stage cap responsible for a deadline failure\.
- `timeoutStage` — Stage that owns a shortened deadline, not necessarily the failing stage\.
- `occurredAt` — Monotonic emission time; absent until delivered to a sink\.
