Creates validated aggregate ceilings for one HTTP client or server instance\.

#### 参数

- `maximumConnections` — Maximum physical connections for the instance\.
- `maximumConnectionsPerRoute` — Maximum connections for one route and origin\.
- `maximumConnectionsPerOrigin` — Maximum connections across routes for one origin\.
- `maximumRequests` — Maximum active requests for the instance\.
- `maximumRequestsPerRoute` — Maximum active requests for one route and origin\.
- `maximumRequestsPerOrigin` — Maximum active requests across routes for one origin\.
- `maximumStreams` — Maximum active HTTP/2 streams for the instance\.
- `maximumStreamsPerRoute` — Maximum active streams for one route and origin\.
- `maximumStreamsPerOrigin` — Maximum active streams across routes for one origin\.
- `maximumManagedBufferBytes` — Aggregate managed HTTP/2 buffer byte ceiling\.
- `reservedControlBufferBytes` — Capacity protected from DATA for control and cleanup frames\.
- `maximumWaiters` — Maximum waiters on aggregate resource admission\.
- `maximumManagedBufferBytesPerRoute` — DATA\-buffer bytes for one route and origin\.
- `maximumManagedBufferBytesPerOrigin` — DATA\-buffer bytes across routes for one origin\.
- `maximumOwners` — Maximum concurrent origin/route owner records\.
