Creates a complete, internally consistent DNS message summary\.
Each section count and the combined resource\-record count must fit
16 bits\. Validation precedes copying the question and record arrays\.

#### 参数

- `transactionId` — DNS transaction identifier\.
- `answerCount` — Number of leading answer records in \`records\`\.
- `truncated` — Whether the DNS TC bit is set\.
- `isResponse` — Whether the DNS QR bit is set\.
- `opcode` — Numeric DNS opcode from 0 through 15\.
- `responseCode` — Numeric DNS response code from 0 through 15\.
- `questionCount` — Number of entries in \`questions\`\.
- `authorityCount` — Number of authority records following the answers\.
- `additionalCount` — Number of additional records following authorities\.
- `questions` — Validated question entries; the value owns a copy\.
- `records` — Answer, authority, and additional records in that order; the value owns a copy\.
