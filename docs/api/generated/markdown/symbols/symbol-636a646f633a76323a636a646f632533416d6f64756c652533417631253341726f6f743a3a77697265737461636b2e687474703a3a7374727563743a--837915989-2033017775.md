Creates a point\-in\-time aggregate snapshot\.

#### 参数

- `limits` — Effective configured resource ceilings\.
- `activeConnections` — Currently active physical connections\.
- `activeRequests` — Current active request count\.
- `activeStreams` — Current active HTTP/2 streams\.
- `managedBufferBytes` — Currently admitted managed HTTP/2 bytes\.
- `admissionWaiters` — Current resource\-admission waiter count\.
- `highWaterConnections` — Lifetime maximum active plus reserved connections\.
- `highWaterRequests` — Lifetime maximum active request count\.
- `highWaterStreams` — Lifetime maximum active plus reserved stream count\.
- `highWaterManagedBufferBytes` — Lifetime maximum managed\-buffer bytes\.
- `highWaterAdmissionWaiters` — Lifetime maximum admission waiter count\.
- `owners` — Current origin/route owner rows with activity\.
- `sampledAt` — Monotonic sample instant captured with the ledger counters\.
- `reservedConnections` — Current admitted connections not yet activated\.
- `reservedStreams` — Current admitted streams not yet activated\.
- `rejectedOperations` — Saturating lifetime rejections sampled under the ledger lock\.
- `completedCancellations` — Saturating completed\-cleanup count sampled under the ledger lock\.
- `lastCancellationCompletionLatency` — Last measured cleanup latency, or none before any measurement\.
