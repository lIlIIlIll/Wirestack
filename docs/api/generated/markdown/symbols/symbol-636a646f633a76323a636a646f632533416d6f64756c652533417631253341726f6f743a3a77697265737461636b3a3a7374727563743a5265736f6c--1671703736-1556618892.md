Creates a resolver\-local resource sample\.

#### 参数

- `ownerId` — Positive process\-local resolver owner identifier\.
- `activeQueries` — Admitted queries not yet completed\.
- `queuedQueries` — Queries waiting for work admission\.
- `runningWork` — Actual running resolver work\.
- `cacheEntries` — Current retained DNS cache entries\.
- `rejectedQueries` — Lifetime rejection count\.
- `sampledAt` — Owner\-local monotonic sample instant\.
- `isLive` — False only for a closed owner's last actual sample; sampledAt stays unchanged\.
