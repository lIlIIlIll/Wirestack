Creates validated settings with owned server and suffix arrays\.

#### 参数

- `nameservers` — Up to eight nonzero\-port DNS endpoints, with numeric UInt32 scope IDs when a zone is present\.
- `searchDomains` — Up to sixteen search suffixes\.
- `ndots` — Absolute\-first threshold from zero through fifteen\.
- `hostsPath` — Trusted local regular hosts file, or empty to disable\.
- `queryTimeout` — Positive total lookup budget, at most five minutes\.
- `attempts` — Number of server\-list passes, from one through four\.
- `cacheCapacity` — Cache entry bound, from zero through 4096\.
- `maximumCacheTtl` — Maximum retained TTL, from zero through one day\.

### `wirestack.net.DnsResolverConfig.fromSystem`

```cj
public static func fromSystem(path!: String = "/etc/resolv.conf"): DnsResolverConfig
```

Reads bounded nameserver, search/domain and ndots settings\.
Missing, unreadable, nonregular, oversized or non\-UTF\-8 files yield default settings\.
Unknown directives and invalid entries are ignored\. The last search/domain directive wins\.
Nameserver zones must be numeric UInt32 scope IDs supported by the Linux adapter\.

#### 参数

- `path` — Absolute path to a trusted local regular resolv\.conf file\.
